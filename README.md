# zkh013 — Зэвсэгт хүчний 013 дугаар анги

Next.js (App Router) дээр бичигдсэн ангийн танилцуулах вэбсайт. Clerk-ээр нэвтрэлт/эрх,
MongoDB-д мэдээ (news) болон холбоо барих зурвасуудыг хадгална.

## Эрхийн тогтолцоо

- **Админ** — бүх зүйлийг удирдана: мэдээ нийтлэх/засах/устгах, мэдээг зөвшөөрөх/татгалзах,
  мөн `/admin/users` хуудаснаас хэрэглэгчдэд Админ/Хянагч эрх олгож хандах эрхийг шийднэ.
- **Хянагч** — шинээр орж ирсэн мэдээг `/admin/news`-с хянаж, зөвшөөрөх (нийтлэх) эсвэл
  татгалзах эрхтэй.
- Шинэ мэдээ үргэлж "Хяналтад" (pending) төлөвтэй үүсэж, хянагч/админ зөвшөөрсний дараа
  нийтлэгдэнэ.

## Ангийн тухай (түүх)

Нүүр хуудсын "Ангийн тухай" хэсэгт ангийн товч намтар, түүхэн замнал, түүхэн хүмүүс (Р.Гаваа,
М.Жанчив), шагнал одон харагдана. Агуулга нь `lib/unit-history.ts` файлд, баримт бүр эх
сурвалжийн холбоостойгоо байгаа — засварлах, нэмэхдээ эх сурвалжийг нь хамт оруулна уу.
Хөрөг, архивын баримт, одонгийн зургууд `public/history/` хавтсанд байна.
Үйл явдал/хүн дээр дарахад дэлгэрэнгүй цонх нээгдэх бөгөөд хаяг нь хуваалцаж болох холбоос болно
(жишээ нь `/#tuukh-1936`, `/#hun-gavaa`).

## Мэдээний хэсэг

- `/news` — онцлох мэдээ, 3 баганат жагсаалт, хайлт (`?q=`), хуудаслалт (`?page=`).
- `/news/[id]` — зургийн цомог (дарахад томорно), хуваалцах товч, хажуугийн "Сүүлийн мэдээ",
  өмнөх/дараагийн мэдээ. Facebook-т хуваалцахад мэдээний гарчиг, зураг гарна.
- Нүүр хуудсанд сүүлийн 3 мэдээ харагдана.
- Мэдээ нэмэх/засах формд **нүүр зураг** болон **зургийн цомог** (олон зургийг нэг дор, 30 хүртэл)
  оруулна; цомгийн зургийг ☆ дарж нүүр зураг болгож болно.
- **Бичлэг** (MP4, WEBM, MOV — нэг мэдээнд 5 хүртэл, тус бүр 2GB хүртэл) оруулбал мэдээн дотор сайт
  өөрөө тоглуулна. Файлыг 4MB-аар хэсэгчлэн илгээдэг тул сүлжээ тасарвал тасарсан газраасаа үргэлжилнэ.
  Нүүр зураг хоосон бол бичлэгийн нэг кадр автоматаар нүүр зураг болно. YouTube/Facebook холбоос хэвээр
  ажиллана.
- Лого: `public/logo.png`; таб дээрх icon нь `app/favicon.ico`, `app/icon.png`, `app/apple-icon.png`;
  сайтыг хуваалцахад гарах зураг нь `public/og-image.jpg`.

## Мэдээнд YouTube / Facebook хавсаргах

Мэдээ нэмэх/засах формын "YouTube / Facebook холбоос" талбарт видео эсвэл постын холбоосыг
хуулж оруулахад мэдээн дотор тухайн видео/пост гарч ирнэ (`lib/media.ts`).

- **YouTube** (`watch`, `youtu.be`, `shorts`, `live`) — видео тоглуулагч гарна. Зургийн талбар
  хоосон бол видеоны зураг автоматаар бөглөгдөж, мэдээний жагсаалт болон нүүр хуудсанд харагдана.
- **Facebook** видео, reel, пост (`share/...`, `fb.watch` богино холбоос ч болно) — Facebook-ийн
  албан ёсны embed-ээр гарна. Пост нь нийтэд (Public) нээлттэй байх ёстой. Видео/постын зураг нүүр
  зураг болж автоматаар бөглөгдөнө.
- Нүүр зураг болон цомгийн талбарт **Facebook зургийн холбоос** оруулж болно — жинхэнэ зургийг нь
  олж, мэдээг хадгалах үед манай Vercel Blob руу хуулна (`lib/image-import.ts`; Facebook-ийн зургийн
  хаяг хэд хоногийн дараа хүчингүй болдог тул).

## Монгол бичгийн горим (MN / MGL)

Цэсний **MN | MGL** товчоор сайтыг кирилл (MN) болон монгол бичгээр (MGL) үзнэ. Сонголт `script`
cookie-д хадгалагдана. MGL горимд бичвэр босоо баганаар (зүүнээс баруун тийш) уншигдах тусдаа
загвартай: зүүн талын босоо цэс, MN-ийнх шиг доошоо урсдаг түүхэн замнал, босоо мэдээ гэх мэт
(`components/mgl/`, `components/unit-history-mgl.tsx`). Хөрвүүлэлтэд Bolorsoft-ын
[Kimo](https://kimo.mngl.net/) үйлчилгээг ашигладаг.

- **Фонт** — Bolorsoft-ын үнэгүй "Classical Mongolian Dashtseden" (Т.Жамъянсүрэн) фонт,
  `public/fonts/dashtseden-5.91.ttf` (фонт доторх лицензээр хувийн болон арилжааны зорилгоор үнэгүй
  түгээж, ашиглаж болно). Зөвхөн MGL горимд, монгол бичгийн тэмдэгтэд татагдана; латин үсэг, тоо
  Geist-ээр харагдана. Фонтыг сольбол файлын нэрийг өөрчилж, `lib/mgl/shared.ts`-ийн `MGL_FONT_URL`
  болон `app/globals.css`-ийн `@font-face`-ийг хамт шинэчилнэ (файл 1 жил cache-лэгддэг).
- **Хээ угалз** — өлзий хээ, алхан хээ, хүрээний булан `components/mgl/mgl-ornaments.tsx`-д, алтлаг
  өнгө нь `--gold` (`text-gold`).
- **Тоо** — MGL горимд бүх тоо монгол цифрээр (1929 → ᠑᠙᠒᠙, огноо ᠒᠐᠒᠖᠂᠑᠐᠂᠑᠖) босоо урсана
  (`mglDigits`, `mglDate` — `lib/mgl/shared.ts`). `t()` болон `toMgl()` автоматаар хөрвүүлдэг; MGL
  хэсэгт кодонд шууд бичсэн тоог (огноо, утас, тоолуур) `mglDigits()`-ээр ороож харуулна. И-мэйл,
  холбоос доторх тоо хэвээр үлдэнэ.

- **Сайтын тогтмол бичвэр** (цэс, гарчиг, түүх, хаяг) — `lib/mgl/dictionary.json` толь бичгээс
  авна. Кодонд шинэ бичвэр нэмбэл `t("...")`-ээр ороож, `npm run mgl:sync` ажиллуулж толь бичгийг
  шинэчилнэ (`npm run mgl:check` — дутуу бичвэр байгаа эсэхийг шалгана). Буруу хөрвүүлсэн үгийг
  `dictionary.json`-д гараар засаж болно.
- **Мэдээ, сургалтын материал** — хадгалах үед болон анх үзэхэд Kimo-оор хөрвүүлж MongoDB-ийн
  `mglcaches` цуглуулгад хадгална (`lib/mgl/convert.ts`). Хөрвүүлж амжаагүй мөр түр кириллээр
  харагдаад дараагийн удаа монгол бичгээр гарна.
- Kimo нь хүсэлтийн тоог хязгаарладаг тул бөөнөөр нь хөрвүүлэхдээ завсарлагатай ажилладаг.

## Локал дээр ажиллуулах

```bash
npm install
cp .env.local.example .env.local   # утгуудаа бөглөнө
npm run dev
```

`http://localhost:3000` дээр нээгдэнэ.

### Орчны хувьсагчид (`.env.local`)

- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` — https://dashboard.clerk.com
  (эсвэл `npx clerk@latest init --accountless` ажиллуулбал нэвтрэхгүйгээр түр зуурын
  dev key автоматаар үүснэ — бид эхлээд үүгээр туршилаа).
- `MONGODB_URI` — MongoDB Atlas холболтын мөр. **Хоосон/жишээ утгаараа орхивол** local
  dev-д автоматаар түр зуурын in-memory MongoDB ашиглана (server дахин асаах бүрд
  өгөгдөл шинээр эхэлнэ) — `lib/mongodb.ts`-г үзнэ үү. Production дээр (Vercel) заавал
  бодит Atlas URI тохируулах шаардлагатай.
- `INITIAL_ADMIN_EMAILS` — Clerk дээр гараар role тохируулах шаардлагагүйгээр, энд
  бүртгэсэн и-мэйлээр анх удаа нэвтэрсэн хэрэглэгч автоматаар **admin** эрхтэй болно.
  Дараа нь бусад хэрэглэгчдэд `/admin/users` хуудаснаас эрх өгч болно.

## Vercel

Сайт одоо ангийн сервер дээр (`unit013.mn`) ажилладаг. Vercel дээрх хуучин хуулбар `git push` бүрд deploy
хийгдсэн хэвээр ч бүх хүсэлтийг `https://unit013.mn` руу байнга шилжүүлнэ (`next.config.ts`) — өөр өгөгдлийн
сантай хуулбар Google-д давхардал үүсгэхгүйн тулд.

## Хайлтын систем (Google)

- `app/robots.ts` → `/robots.txt` (админ, нэвтрэх хуудас, API-г хайлтаас хасна); `app/sitemap.ts` →
  `/sitemap.xml` (нүүр, мэдээ — шинээр нийтлэгдсэн мэдээ шууд орно).
- Нүүр хуудсанд JSON-LD (`WebSite`, `GovernmentOrganization`) — Google-д сайтын нэр, байгууллага, лого.
- Google Search Console-д `unit013.mn`-ийг бүртгэж, `https://unit013.mn/sitemap.xml`-ийг илгээнэ.
- Сервер Clerk-ийн **production** түлхүүр ашиглана. Dev түлхүүртэй үед cookie-гүй хүсэлт бүр (Google-ийн
  робот ч) `clerk.accounts.dev` руу шилждэг тул сайт хайлтад орж чаддаггүй.
- Clerk production-ийн DNS бичлэгүүд (`clerk`, `accounts`, `clkmail`, `clk._domainkey`, `clk2._domainkey`)
  Cloudflare-д **DNS only** (саарал үүл) байх ёстой. Google-ээр нэвтрэхэд OAuth тохиргоо хийгээгүй тул
  нэвтрэх/бүртгүүлэх цонхноос Google товчийг нуусан (`app/sign-in`, `app/sign-up`).

## Өөрийн сервер дээр ажиллуулах

Ангийн сервер (Ubuntu, `/home/chinzu1k/zkh013`) дээр сайт, MongoDB, зураг/бичлэг бүгд нэг дор байна.
Тохиргооны файлууд `deploy/` хавтсанд:

- `zkh013.service` — сайтыг systemd-ээр ажиллуулна (`-H localhost` заавал — файл доторх тайлбарыг үзнэ үү).
- `nginx-zkh013.conf` — 80 портоос сайт руу дамжуулж, `/uploads/` доторх файлыг дискнээс шууд өгнө.
- `backup.sh`, `zkh013-backup.service`, `zkh013-backup.timer` — өдөр бүр MongoDB-ийн хуулбар
  (`/srv/zkh013/backups`, 14 хоног).
- `cloudflared-config.yml` — интернэтээс `unit013.mn`-ээр хандах Cloudflare Tunnel-ийн тохиргоо.

**Интернэт:** `unit013.mn` (Datacom-д бүртгэлтэй) Cloudflare-ын нэрийн серверүүдийг ашиглана. Сервер
Cloudflare руу өөрөө гадагш холбогддог (`cloudflared` үйлчилгээ, tunnel `zkh013`) тул роутерт порт нээх
шаардлагагүй, HTTPS-ийг Cloudflare өгнө. Firewall (`ufw`) SSH болон 80 портыг зөвхөн дотоод сүлжээнд нээсэн.
`.env.local`-д `NEXT_PUBLIC_SITE_URL=https://unit013.mn`.

**Файл хадгалах:** `.env.local`-д `UPLOAD_DIR=/srv/zkh013/uploads` тохируулсан бол зураг, бичлэг, сургалтын
файл серверийн дискэнд хадгалагдаж `/uploads/...` хаягаар нээгдэнэ. Тохируулаагүй бол (Vercel) Vercel Blob-д
хадгалагдана (`lib/storage.ts`).

**MongoDB** Docker дотор (`zkh013-mongo`, зөвхөн `127.0.0.1:27017`) ажиллана; өгөгдөл `/srv/zkh013/mongo`-д.

**Шинэчлэх:**

```bash
cd ~/zkh013 && git pull && npm ci && npm run build && sudo systemctl restart zkh013
```

**Нөөц хуулбар:** `/srv/zkh013/backups` болон `/srv/zkh013/uploads`-ийг өөр диск/компьютер руу үе үе хуулж
байгаарай — сервер эвдэрвэл өгөгдөл зөвхөн тэнд л үлдэнэ.
