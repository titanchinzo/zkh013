# zkh013 — Зэвсэгт хүчний 013 дугаар анги

Next.js (App Router) дээр бичигдсэн ангийн танилцуулах вэбсайт. Clerk-ээр нэвтрэлт/эрх,
MongoDB-д мэдээ (news) болон холбоо барих зурвасуудыг хадгална.

## Эрхийн тогтолцоо

- **Админ** — бүх зүйлийг удирдана: мэдээ нийтлэх/засах/устгах, мэдээг зөвшөөрөх/татгалзах,
  мөн `/admin/users` хуудаснаас хэрэглэгчдэд Админ/Хянагч эрх олгож хандах эрхийг шийднэ.
- **Хянагч** — шинээр орж ирсэн мэдээг `/admin/news`-с хянаж, зөвшөөрөх (нийтлэх) эсвэл
  татгалзах эрхтэй.
- Шинэ мэдээ үргэлж "Хяналтад" (pending) төлөвтэй үүсэж, хянагч/админ зөвшөөрсний дараа
  нийтлэгдэнэ.

## Ангийн тухай (түүх)

Нүүр хуудсын "Ангийн тухай" хэсэгт ангийн товч намтар, түүхэн замнал, түүхэн хүмүүс (Р.Гаваа,
М.Жанчив), шагнал одон харагдана. Агуулга нь `lib/unit-history.ts` файлд, баримт бүр эх
сурвалжийн холбоостойгоо байгаа — засварлах, нэмэхдээ эх сурвалжийг нь хамт оруулна уу.
Хөрөг, архивын баримт, одонгийн зургууд `public/history/` хавтсанд байна.
Үйл явдал/хүн дээр дарахад дэлгэрэнгүй цонх нээгдэх бөгөөд хаяг нь хуваалцаж болох холбоос болно
(жишээ нь `/#tuukh-1936`, `/#hun-gavaa`).

## Мэдээний хэсэг

- `/news` — онцлох мэдээ, 3 баганат жагсаалт, хайлт (`?q=`), хуудаслалт (`?page=`).
- `/news/[id]` — зургийн цомог (дарахад томорно), хуваалцах товч, хажуугийн "Сүүлийн мэдээ",
  өмнөх/дараагийн мэдээ. Facebook-т хуваалцахад мэдээний гарчиг, зураг гарна.
- Нүүр хуудсанд сүүлийн 3 мэдээ харагдана.
- Мэдээ нэмэх/засах формд **нүүр зураг** болон **зургийн цомог** (олон зургийг нэг дор, 30 хүртэл)
  оруулна; цомгийн зургийг ☆ дарж нүүр зураг болгож болно.
- Лого: `public/logo.png`; таб дээрх icon нь `app/favicon.ico`, `app/icon.png`, `app/apple-icon.png`;
  сайтыг хуваалцахад гарах зураг нь `public/og-image.jpg`.

## Мэдээнд YouTube / Facebook хавсаргах

Мэдээ нэмэх/засах формын "YouTube / Facebook холбоос" талбарт видео эсвэл постын холбоосыг
хуулж оруулахад мэдээн дотор тухайн видео/пост гарч ирнэ (`lib/media.ts`).

- **YouTube** (`watch`, `youtu.be`, `shorts`, `live`) — видео тоглуулагч гарна. Зургийн талбар
  хоосон бол видеоны зураг автоматаар бөглөгдөж, мэдээний жагсаалт болон нүүр хуудсанд харагдана.
- **Facebook** видео, reel, пост (`share/...`, `fb.watch` богино холбоос ч болно) — Facebook-ийн
  албан ёсны embed-ээр гарна. Пост нь нийтэд (Public) нээлттэй байх ёстой. Видео/постын зураг нүүр
  зураг болж автоматаар бөглөгдөнө.
- Нүүр зураг болон цомгийн талбарт **Facebook зургийн холбоос** оруулж болно — жинхэнэ зургийг нь
  олж, мэдээг хадгалах үед манай Vercel Blob руу хуулна (`lib/image-import.ts`; Facebook-ийн зургийн
  хаяг хэд хоногийн дараа хүчингүй болдог тул).

## Локал дээр ажиллуулах

```bash
npm install
cp .env.local.example .env.local   # утгуудаа бөглөнө
npm run dev
```

`http://localhost:3000` дээр нээгдэнэ.

### Орчны хувьсагчид (`.env.local`)

- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY` — https://dashboard.clerk.com
  (эсвэл `npx clerk@latest init --accountless` ажиллуулбал нэвтрэхгүйгээр түр зуурын
  dev key автоматаар үүснэ — бид эхлээд үүгээр туршилаа).
- `MONGODB_URI` — MongoDB Atlas холболтын мөр. **Хоосон/жишээ утгаараа орхивол** local
  dev-д автоматаар түр зуурын in-memory MongoDB ашиглана (server дахин асаах бүрд
  өгөгдөл шинээр эхэлнэ) — `lib/mongodb.ts`-г үзнэ үү. Production дээр (Vercel) заавал
  бодит Atlas URI тохируулах шаардлагатай.
- `INITIAL_ADMIN_EMAILS` — Clerk дээр гараар role тохируулах шаардлагагүйгээр, энд
  бүртгэсэн и-мэйлээр анх удаа нэвтэрсэн хэрэглэгч автоматаар **admin** эрхтэй болно.
  Дараа нь бусад хэрэглэгчдэд `/admin/users` хуудаснаас эрх өгч болно.

## Vercel дээр deploy хийх

1. Vercel project-ийн Environment Variables-д дээрх хувьсагчдыг (бодит утгуудаар нь)
   нэмнэ — `MONGODB_URI` нь заавал бодит Atlas URI байх ёстой.
2. Clerk dashboard-д production instance үүсгэж (эсвэл одоогийн dev instance-аа
   ашиглаж), `pk_live_...` / `sk_live_...` key-үүдийг тохируулна.
3. `git push` хийсний дараа Vercel автоматаар deploy хийнэ.
