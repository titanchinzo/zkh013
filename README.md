# zkh013 — Зэвсэгт хүчний 013 дугаар анги

Next.js (App Router) дээр бичигдсэн ангийн танилцуулах вэбсайт. Clerk-ээр нэвтрэлт/эрх,
MongoDB-д мэдээ (news) болон холбоо барих зурвасуудыг хадгална.

## Эрхийн тогтолцоо

- **Админ** — бүх зүйлийг удирдана: мэдээ нийтлэх/засах/устгах, мэдээг зөвшөөрөх/татгалзах,
  мөн `/admin/users` хуудаснаас хэрэглэгчдэд Админ/Хянагч/Нийтлэгч эрх олгож хандах эрхийг шийднэ.
- **Хянагч** — шинээр орж ирсэн мэдээг `/admin/news`-с хянаж, зөвшөөрөх (нийтлэх) эсвэл
  татгалзах эрхтэй.
- **Нийтлэгч** — мэдээ бэлтгэж оруулна. `/admin/news`-д зөвхөн өөрийн мэдээ харагдах бөгөөд
  нийтлэгдэх хүртэл (хяналтад эсвэл татгалзсан үед) засна; засвар нь мэдээг дахин хяналтад оруулна.
- Шинэ мэдээ үргэлж "Хяналтад" (pending) төлөвтэй үүсэж, хянагч/админ зөвшөөрсний дараа
  нийтлэгдэнэ.
- **Хянах самбар** (`/admin`) — карт бүр дээр дарахад тухайн хэсэг рүү (мэдээ төлвөөр нь шүүгдэж) орно.
- **Ирсэн зурвас** (`/admin/messages`, зөвхөн админ) — сайтын «Холбоо барих» маягтаар ирсэн зурвасууд.
- **Хэрэглэгч нэмэх, хаах, устгах** (`/admin/users`): и-мэйл, эрхийг нь сонгоод **Нэмэх** (бүртгэлийг шууд
  үүсгэнэ — тэр хүн `/sign-in` дээр и-мэйлээ бичээд ирсэн кодоор нэвтэрнэ) эсвэл **Урилга илгээх** (и-мэйлээр
  урилгын холбоос очно). **Хаах** — нэвтэрч чадахгүй болж, утасны апп нь ч хаагдана; **Устгах** — бүр мөсөн
  (алба хаагчийн бүртгэл үлдэнэ). Өөрөө `/sign-up`-аар бүртгүүлсэн хүн "Эрхгүй" байна. Админ өөрийгөө
  хааж, устгаж, эрхээ өөрчилж чадахгүй.
- **Хүний нөөц** — мэдээтэй ажиллахгүй; доорх "Хүний нөөц, зарлан мэдээлэх" хэсгийг удирдана.

## Хүний нөөц, зарлан мэдээлэх (нийтэд биш)

Зөвхөн **админ** болон **хүний нөөц** эрхтэй хүнд `/admin`-д харагдана:

- `/admin/attendance` — **Ирц, харуул хоногийн манаа**: **харуул хоногийн манаа** (нэг л төрлийн үүрэг)-г 7 хоногоор
  (Даваа–Ням) гаргаж, өдөр бүрд хүмүүсийг нь сонгоно; сонгосон өдрийн ирцийг (Ирсэн, Чөлөөтэй, Өвчтэй,
  Томилолттой, Ээлжийн амралттай, Тасалсан) тэмдэглэнэ. Томилогдсон хүнд «Таныг томиллоо: … (3 хоногийн дараа)»
  мэдэгдэл очиж, манаанд гарах өдрөө **11 цагаас хойш** «Тайван хоноорой!» мэдэгдэл авна (`lib/duty-reminders.ts`,
  сервер асахад `instrumentation.ts`-ээс эхэлж 5 минут тутам шалгана; ✓ — мэдэгдэл очсон).
- `/admin/personnel` — **Алба хаагчид**: цол, нэр, албан тушаал, **утасны дугаар (заавал, 8 оронтой)**, профайл зураг.
  Цолыг жагсаалтаас сонгоно (`lib/hr.ts`-ийн `RANKS`: энг, т/ч, а/т, д/а, а/ч, а/а, с/а, т/а, д/ч, а/д, а/х, х/ч,
  д/х, Хур). Хүний нөөц бүх мэдээллийг (үг үсгийн алдаа г.м) засна. Халагдсан хүнийг «Идэвхгүй болгох»-д ирц,
  хуваарийн түүх нь үлдэнэ. «Устгах» нь бүр мөсөн устгана: ирц, хуваарийн бүх өдрөөс хасаж, утасны аппыг нь хаана
  (дахин бүртгүүлэхэд хүний нөөц зөвшөөрнө). Мөн түүнд ирсэн чатын зурвас, түүний болон түүнд илгээсэн
  хүлээгдэж буй урилгыг устгана. Сайтын бүртгэлийг (Clerk) админ «Хэрэглэгчид»-ээс устгана.
  - **Урьдчилж бүртгэх** — хүний нөөц хүмүүсээ «Гараар нэмэх»-ээр (утасны дугаартай нь) түрүүлж оруулж, ирц, хуваарь
    гаргаж болно. Тэр хүн дараа нь аппаар бүртгүүлэхэд **ижил утасны дугаараар** нь тэр бүртгэлтэй холбогдож
    давхардахгүй: урилгаар орж ирсэн бол автоматаар, өөрөө хүсэлт илгээсэн бол «Утасны бүртгэл»-д тэр бүртгэл
    урьдчилан сонгогдсон байна. Ижил дугаартай холбогдоогүй бүртгэл хэд байвал (дундын утас) автоматаар холбохгүй.
  - **И-мэйлээр урих** — урилгаар орж ирсэн хүн аппаа татаж, бүртгэлээ (утас, зураг) **хүний нөөцийн зөвшөөрөл
    хүлээлгүй** өөрөө шууд үүсгэнэ. Аль хэдийн бүртгэлтэй алба хаагчийг сонгож урьвал түүнтэй холбогдоно.
  - **Бүртгэх эрх** (checkbox) — албадын дарга нарт олгоно; тэд утсан дээрх аппын «Хүн бүртгэх» хэсгээс доод
    хүмүүсээ и-мэйлээр урьж, хэн бүртгүүлснийг харна. Жагсаалтад хэн урьсан нь харагдана.
  - Админы нэмсэн/урьсан ажилтан (хянагч, нийтлэгч г.м) ч мөн адил бүртгэлээ шууд үүсгэж, апп татна.
  - Урилгаар орж ирсэн хүний зөвхөн **анхны** утас шууд идэвхжинэ; утсаа солих, гээсэн үед хүний нөөц зөвшөөрнө.
- `/admin/devices` — **Утасны бүртгэл**: апп суулгасан хүмүүсийн хүсэлтийг зөвшөөрнө/татгалзана.
- `/admin/alerts` — **Зарлан мэдээлэх**: бичсэн мэдээлэл зөвшөөрөгдсөн бүх утсанд мэдэгдлээр очиж, хэн
  "Хүлээн авлаа" дарсан, хэн дараагүйг харуулна.
  - Мэдээлэл бүр **хугацаатай**: эхлэх (хоосон бол одоо) ба дуусах цаг сонгоно. Хугацааны товчнууд байна (1 цаг …
    30 хоног).
  - Эхлэх цаг нь ирээгүй мэдээлэл товлогдоно. Утсанд мэдэгдэл тэр цагт очно, сервер 30 секунд тутам шалгана
    (`lib/alerts.ts`, `instrumentation.ts`).
  - Дуусах цаг өнгөрмөгц апп, энэ жагсаалтаас тэр дороо алга болно. Өгөгдлийн сангаас MongoDB-ийн TTL index
    (`endsAt`) нэг минутын дотор «Хүлээн авлаа» тэмдэглэлийн хамт устгана.
  - **Засах**: гарчиг, текст, хугацааг өөрчилнө. «Утсанд дахин мэдэгдэх»-ийг сонговол мэдэгдэл дахин очиж,
    хүлээн авсан тэмдэглэл шинээр эхэлнэ.
  - **Устгах**: утсан дээрээс ч арилна.
  - Хугацаатай болохоос өмнө илгээсэн мэдээлэл «Дуусах хугацаагүй» харагдана. Засаж хугацаа тавих эсвэл устгана.

**Утсан дээрх апп** (`/app`, PWA — App Store/Play Store хэрэггүй, үнэгүй). Сайтын цэсний **Апп татах**
(`/download`) хуудсанд татах товч, iPhone/Android-ийн заавар, компьютерээс нээсэн хүнд QR код (`public/app-qr.png`)
байна; хүний нөөцийн «Утасны бүртгэл» хуудсанд ч QR харагдана.

1. Алба хаагч https://unit013.mn/download-ыг утсаараа нээж **нүүр дэлгэцэндээ суулгана** (iPhone: Safari → Хуваалцах →
   Add to Home Screen; Android: Chrome → ⋮ → Install app). Суулгасан апп-д зарлан мэдээлэл, тухайн хүний харуул,
   манаа, алба хаагчдын чат харагдана.
2. Суулгасан аппаас **и-мэйлээрээ** бүртгүүлж/нэвтэрч, цол, нэр, албан тушаал, утасны дугаараа бичээд хүсэлт
   илгээнэ (урилгаар орж ирсэн бол «Бүртгэл үүсгэх» — шууд идэвхжинэ). Апп дээр «Бүртгэлээ засах», профайл зураг
   солих боломжтой.
3. Хүний нөөц `/admin/devices`-ээс зөвшөөрөхдөө алба хаагчтай холбоно (эсвэл шинээр бүртгэнэ) — утасны дугаар эсвэл
   нэр нь таарсан бүртгэл урьдчилан сонгогдсон байна. Урилга заавал биш. Шинэ хүсэлт тэр хуудсанд 15 секундын
   дотор өөрөө гарч ирнэ. Хүлээж буй хүний апп 10 секунд тутам шалгаж, зөвшөөрмөгц өөрөө нээгдэнэ.
   Апп-д зарлан мэдээлэл, «Та 3 хоногийн дараа харуул хоногийн манаанд гарна» гэсэн сануулга, энэ болон дараагийн
   7 хоногийн хуваарь (бүх хүнийх, өөрийнх нь тодорсон) харагдана.
4. Апп дээр "Мэдэгдэл асаах" дарна. iPhone дээр мэдэгдэл зөвхөн iOS 16.4+ ба нүүр дэлгэцэнд суулгасан аппад ажиллана.

- **Чат** (зөвхөн утсан дээрх апп-д, доод цэсний «Чат»): апп ашиглаж буй (хүний нөөц зөвшөөрсөн утастай) алба
  хаагчид хоорондоо хоёр хүний чат бичнэ.
  - Апп-аа нээлттэй байгаа хүн ногоон цэгтэй, «Одоо идэвхтэй» хэсэгт харагдана. Бусдад «5 минутын өмнө идэвхтэй
    байсан» гэх мэтээр харагдана. Илгээсэн зурвасыг нөгөө хүн уншсан бол «Уншсан» гэж гарна.
  - Апп хаалттай үед шинэ зурвас утсанд мэдэгдлээр очиж, аппын дүрс дээр уншаагүй тоо гарна. Тухайн чатыг нээж
    харж байгаа хүнд мэдэгдэл давхар очихгүй.
  - Нэг зурвас 2000 тэмдэгт хүртэл, нэг хүн минутад 30 хүртэл зурвас илгээнэ. Халагдсан (идэвхгүй болгосон) хүнд
    бичих боломжгүй, өмнөх чат нь утсан дээр үлдэнэ.
  - Апп нээлттэй үед утас сервер рүү хэдэн секунд тутам асууж шинэ зурвас авна (чат дотор 2.5 с, жагсаалт 10 с).
  - **Чат серверт хадгалагдахгүй.** Сервер (MongoDB `chatmessages`) зөвхөн хүлээн авагч хараахан уншаагүй зурвасыг
    түр барина. Хүлээн авагчийн утас зурвасыг авч өөртөө хадгалмагц (`?ack=`) серверээс устгана. Огт нээгээгүй
    зурвас 30 хоногийн дараа өөрөө устна. Өдөр бүрийн нөөц хуулбарт (`deploy/backup.sh`) чатын зурвас орохгүй.
  - Чатын түүх зөвхөн хоёр хүний утсанд (хөтчийн IndexedDB, `lib/chat-store.ts`) нэг хүнтэй 500 зурвас хүртэл
    хадгалагдана. Утсаа солих, апп-аа устгахад түүх алга болно. Хүний нөөц утсыг хүчингүй болгоход (гээсэн г.м) тэр
    утсан дээрх түүх дараагийн нээлтэд арчигдана. Сайтын админ хэсэгт чат огт харагдахгүй.
  - Код: `app/api/app/chat`, `lib/chat.ts`, `lib/chat-store.ts`, `components/app/chat.tsx`. Өмнөх хувилбарын серверт
    хадгалсан чатыг `lib/chat-migrate.ts` сервер асахад нэг удаа цэвэрлэнэ.
- **Нэг хүн — нэг утас.** Шинэ утаснаас хүсэлт ирж хүний нөөц зөвшөөрөхөд хуучин утас автоматаар хүчингүй болно.
  Гээсэн утсыг "Хүчингүй болгох"-оор хааж, хүсвэл тэр хүнийг сайтын бүх нэвтрэлтээс гаргана.
- Утсыг httpOnly cookie-д хадгалсан санамсаргүй түлхүүрээр (өгөгдлийн санд зөвхөн hash нь) таньдаг. Зөвшөөрсний
  дараа Clerk-ийн нэвтрэлт (үнэгүй багцад 7 хоног) дуусахад ч апп ажилласаар байна.
- **Яагаад SMS биш, и-мэйл вэ:** Clerk-ийн SMS баталгаажуулалт зөвхөн төлбөртэй багцад ($25/сар + SMS бүрт
  төлбөр), и-мэйлийн код үнэгүй. Gmail заавал биш — ямар ч и-мэйл болно.
- **Мэдэгдэл (Web Push)** — Google, Apple-ийн push үйлчилгээгээр үнэгүй. Сервер дээр `.env.local`-д нэг удаа:
  `npx web-push generate-vapid-keys`-ээр гаргасан `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` нэмнэ
  (сольвол бүх утас мэдэгдлээ дахин асаана).

## Ангийн тухай (түүх)

Нүүр хуудсын "Ангийн тухай" хэсэгт ангийн товч намтар, түүхэн замнал, түүхэн хүмүүс (Р.Гаваа,
М.Жанчив), шагнал одон харагдана. Агуулга нь `lib/unit-history.ts` файлд, баримт бүр эх
сурвалжийн холбоостойгоо байгаа — засварлах, нэмэхдээ эх сурвалжийг нь хамт оруулна уу.
Хөрөг, архивын баримт, одонгийн зургууд `public/history/` хавтсанд байна.
Үйл явдал/хүн дээр дарахад дэлгэрэнгүй цонх нээгдэх бөгөөд хаяг нь хуваалцаж болох холбоос болно
(жишээ нь `/#tuukh-1936`, `/#hun-gavaa`).

## Мэдээний хэсэг

- `/news` — онцлох мэдээ, 3 баганат жагсаалт, хайлт (`?q=`), хуудаслалт (`?page=`).
- `/news/[id]` — зургийн цомог (дарахад томорно), хуваалцах товч, хажуугийн "Сүүлийн мэдээ",
  өмнөх/дараагийн мэдээ. Facebook-т хуваалцахад мэдээний гарчиг, зураг гарна.
- Нүүр хуудсанд сүүлийн 3 мэдээ харагдана.
- Мэдээ нэмэх/засах формд **нүүр зураг** болон **зургийн цомог** (олон зургийг нэг дор, 30 хүртэл)
  оруулна; цомгийн зургийг ☆ дарж нүүр зураг болгож болно.
- **Бичлэг** (MP4, WEBM, MOV — нэг мэдээнд 5 хүртэл, тус бүр 2GB хүртэл) оруулбал мэдээн дотор сайт
  өөрөө тоглуулна. Файлыг 4MB-аар хэсэгчлэн илгээдэг тул сүлжээ тасарвал тасарсан газраасаа үргэлжилнэ.
  Нүүр зураг хоосон бол бичлэгийн нэг кадр автоматаар нүүр зураг болно. YouTube/Facebook холбоос хэвээр
  ажиллана.
- Лого: `public/logo.png`; таб дээрх icon нь `app/favicon.ico`, `app/icon.png`, `app/apple-icon.png`;
  сайтыг хуваалцахад гарах зураг нь `public/og-image.jpg`.

## Мэдээнд YouTube / Facebook хавсаргах

Мэдээ нэмэх/засах формын "YouTube / Facebook холбоос" талбарт видео эсвэл постын холбоосыг
хуулж оруулахад мэдээн дотор тухайн видео/пост гарч ирнэ (`lib/media.ts`).

- **YouTube** (`watch`, `youtu.be`, `shorts`, `live`) — видео тоглуулагч гарна. Зургийн талбар
  хоосон бол видеоны зураг автоматаар бөглөгдөж, мэдээний жагсаалт болон нүүр хуудсанд харагдана.
- **Facebook** видео, reel, пост (`share/...`, `fb.watch` богино холбоос ч болно) — Facebook-ийн
  албан ёсны embed-ээр гарна. Пост нь нийтэд (Public) нээлттэй байх ёстой. Видео/постын зураг нүүр
  зураг болж автоматаар бөглөгдөнө.
- Нүүр зураг болон цомгийн талбарт **Facebook зургийн холбоос** оруулж болно — жинхэнэ зургийг нь
  олж, мэдээг хадгалах үед манай Vercel Blob руу хуулна (`lib/image-import.ts`; Facebook-ийн зургийн
  хаяг хэд хоногийн дараа хүчингүй болдог тул).

## Монгол бичгийн горим (MN / MGL)

Цэсний **MN | MGL** товчоор сайтыг кирилл (MN) болон монгол бичгээр (MGL) үзнэ. Сонголт `script`
cookie-д хадгалагдана. MGL горимд бичвэр босоо баганаар (зүүнээс баруун тийш) уншигдах тусдаа
загвартай: зүүн талын босоо цэс, MN-ийнх шиг доошоо урсдаг түүхэн замнал, босоо мэдээ гэх мэт
(`components/mgl/`, `components/unit-history-mgl.tsx`). Хөрвүүлэлтэд Bolorsoft-ын
[Kimo](https://kimo.mngl.net/) үйлчилгээг ашигладаг.

- **Фонт** — Bolorsoft-ын үнэгүй "Classical Mongolian Dashtseden" (Т.Жамъянсүрэн) фонт,
  `public/fonts/dashtseden-5.91.ttf` (фонт доторх лицензээр хувийн болон арилжааны зорилгоор үнэгүй
  түгээж, ашиглаж болно). Зөвхөн MGL горимд, монгол бичгийн тэмдэгтэд татагдана; латин үсэг, тоо
  Geist-ээр харагдана. Фонтыг сольбол файлын нэрийг өөрчилж, `lib/mgl/shared.ts`-ийн `MGL_FONT_URL`
  болон `app/globals.css`-ийн `@font-face`-ийг хамт шинэчилнэ (файл 1 жил cache-лэгддэг).
- **Хээ угалз** — өлзий хээ, алхан хээ, хүрээний булан `components/mgl/mgl-ornaments.tsx`-д, алтлаг
  өнгө нь `--gold` (`text-gold`).
- **Тоо** — MGL горимд бүх тоо монгол цифрээр (1929 → ᠑᠙᠒᠙, огноо ᠒᠐᠒᠖᠂᠑᠐᠂᠑᠖) босоо урсана
  (`mglDigits`, `mglDate` — `lib/mgl/shared.ts`). `t()` болон `toMgl()` автоматаар хөрвүүлдэг; MGL
  хэсэгт кодонд шууд бичсэн тоог (огноо, утас, тоолуур) `mglDigits()`-ээр ороож харуулна. И-мэйл,
  холбоос доторх тоо хэвээр үлдэнэ.

- **Сайтын тогтмол бичвэр** (цэс, гарчиг, түүх, хаяг) — `lib/mgl/dictionary.json` толь бичгээс
  авна. Кодонд шинэ бичвэр нэмбэл `t("...")`-ээр ороож, `npm run mgl:sync` ажиллуулж толь бичгийг
  шинэчилнэ (`npm run mgl:check` — дутуу бичвэр байгаа эсэхийг шалгана). Буруу хөрвүүлсэн үгийг
  `dictionary.json`-д гараар засаж болно.
- **Мэдээ, сургалтын материал** — хадгалах үед болон анх үзэхэд Kimo-оор хөрвүүлж MongoDB-ийн
  `mglcaches` цуглуулгад хадгална (`lib/mgl/convert.ts`). Хөрвүүлж амжаагүй мөр түр кириллээр
  харагдаад дараагийн удаа монгол бичгээр гарна.
- Kimo нь хүсэлтийн тоог хязгаарладаг тул бөөнөөр нь хөрвүүлэхдээ завсарлагатай ажилладаг.

### Орчны хувьсагчид (`.env.local`)

  (эсвэл `npx clerk@latest init --accountless` ажиллуулбал нэвтрэхгүйгээр түр зуурын

## Vercel

Сайт одоо ангийн сервер дээр (`unit013.mn`) ажилладаг. Vercel дээрх хуучин хуулбар `git push` бүрд deploy
хийгдсэн хэвээр ч бүх хүсэлтийг `https://unit013.mn` руу байнга шилжүүлнэ (`next.config.ts`) — өөр өгөгдлийн
сантай хуулбар Google-д давхардал үүсгэхгүйн тулд.

## Хайлтын систем (Google)

- `app/robots.ts` → `/robots.txt` (админ, нэвтрэх хуудас, API-г хайлтаас хасна); `app/sitemap.ts` →
  `/sitemap.xml` (нүүр, мэдээ — шинээр нийтлэгдсэн мэдээ шууд орно).
- Нүүр хуудсанд JSON-LD (`WebSite`, `GovernmentOrganization`) — Google-д сайтын нэр, байгууллага, лого.
- Google Search Console-д `unit013.mn`-ийг бүртгэж, `https://unit013.mn/sitemap.xml`-ийг илгээнэ.
- Сервер Clerk-ийн **production** түлхүүр ашиглана. Dev түлхүүртэй үед cookie-гүй хүсэлт бүр (Google-ийн
  робот ч) `clerk.accounts.dev` руу шилждэг тул сайт хайлтад орж чаддаггүй.
- Clerk production-ийн DNS бичлэгүүд (`clerk`, `accounts`, `clkmail`, `clk._domainkey`, `clk2._domainkey`)
  Cloudflare-д **DNS only** (саарал үүл) байх ёстой. Google-ээр нэвтрэхэд OAuth тохиргоо хийгээгүй тул
  нэвтрэх/бүртгүүлэх цонхноос Google товчийг нуусан (`app/sign-in`, `app/sign-up`).

## Өөрийн сервер дээр ажиллуулах

Ангийн сервер (Ubuntu, `/home/chinzu1k/zkh013`) дээр сайт, MongoDB, зураг/бичлэг бүгд нэг дор байна.
Тохиргооны файлууд `deploy/` хавтсанд:

- `zkh013.service` — сайтыг systemd-ээр ажиллуулна (`-H localhost` заавал — файл доторх тайлбарыг үзнэ үү).
- `nginx-zkh013.conf` — 80 портоос сайт руу дамжуулж, `/uploads/` доторх файлыг дискнээс шууд өгнө.
- `backup.sh`, `zkh013-backup.service`, `zkh013-backup.timer` — өдөр бүр MongoDB-ийн хуулбар
  (`/srv/zkh013/backups`, 14 хоног).
- `cloudflared-config.yml` — интернэтээс `unit013.mn`-ээр хандах Cloudflare Tunnel-ийн тохиргоо.

**Интернэт:** `unit013.mn` (Datacom-д бүртгэлтэй) Cloudflare-ын нэрийн серверүүдийг ашиглана. Сервер
Cloudflare руу өөрөө гадагш холбогддог (`cloudflared` үйлчилгээ, tunnel `zkh013`) тул роутерт порт нээх
шаардлагагүй, HTTPS-ийг Cloudflare өгнө. Firewall (`ufw`) SSH болон 80 портыг зөвхөн дотоод сүлжээнд нээсэн.
`.env.local`-д `NEXT_PUBLIC_SITE_URL=https://unit013.mn`.

**Файл хадгалах:** `.env.local`-д `UPLOAD_DIR=/srv/zkh013/uploads` тохируулсан бол зураг, бичлэг, сургалтын
файл серверийн дискэнд хадгалагдаж `/uploads/...` хаягаар нээгдэнэ. Тохируулаагүй бол (Vercel) Vercel Blob-д
хадгалагдана (`lib/storage.ts`).

**MongoDB** Docker дотор (`zkh013-mongo`, зөвхөн `127.0.0.1:27017`) ажиллана; өгөгдөл `/srv/zkh013/mongo`-д.

**Шинэчлэх:**

```bash
cd ~/zkh013 && git pull && npm ci && npm run build && sudo systemctl restart zkh013
```

**Нөөц хуулбар:** `/srv/zkh013/backups` болон `/srv/zkh013/uploads`-ийг өөр диск/компьютер руу үе үе хуулж
байгаарай — сервер эвдэрвэл өгөгдөл зөвхөн тэнд л үлдэнэ.
